# InterviewIQ Brand Kit (dark theme)
Mark: human (white suit) + AI robot (teal), on #050505.
- svg/: logo-horizontal (transparent + on-dark), logo-mark, mono-white mark, app-icon, maskable-icon, og-image. Wordmark is outlined (Inter Bold), no font needed.
- png/: icon-192, icon-512, maskable-512, og-image (1200x630), logos at 6x.
- favicon/: favicon.svg, favicon.ico (16/32/48), favicon-16/32/48.png, apple-touch-icon.png, site.webmanifest.
- head-snippet.html: paste into <head>. brand-tokens.css: colours and fonts.
Colours: bg #050505, surface #0B0B0B, border #1F1F1F, text #F5F5F5, muted #A1A1AA, teal #2DD4BF, cyan #22D3EE, violet #A78BFA, amber #FBBF24.
Fonts: Inter (UI), JetBrains Mono (labels).
Notes: copy favicon.ico, favicon.svg, favicon-*.png, apple-touch-icon.png, site.webmanifest to your site root; copy icon-*.png, maskable-512.png, og-image.png as well.
